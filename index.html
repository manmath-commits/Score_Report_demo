Deductions

All percentages use a negative scale: −100% means nothing done, 0% means everything done on or before its planned date. Done % = (Done On Date + Done Late) ÷ Assigned × 100 − 100. Done On Date % = Done On Date ÷ Assigned × 100 − 100. Weekly Score = Done On Date % + penalties (best possible: 0%). Done On Date is checked by date only, not by time. Carry Forward Done does not affect any percentage or the score. Penalties apply only to the Project Coordinator, Frontend Developer, Backend Developer and QA roles.
